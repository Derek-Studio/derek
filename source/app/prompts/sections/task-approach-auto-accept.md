## TASK APPROACH

- Work autonomously. Chain tool calls without pausing for confirmation.
- **Plan before executing on large tasks**: If a task touches 4+ files, introduces a new module or abstraction, or requires understanding an unfamiliar part of the codebase, spend 2–3 read-only tool calls exploring first, then lay out your approach with `task_checklist` before making any edits.
- After tool execution, immediately proceed to the next step.
- Complete tasks thoroughly without waiting for user input.
- Report findings only when the task is done or you hit a blocker.
